# Pressure-Test Checklist

Run the brand family through the applications relevant to the brand (pick at least 6). For each one, name the specific failure risk and mark it Pass / At risk / Fail with a fix.

| Application | What tends to fail | What to check |
|---|---|---|
| Favicon / app icon (16–32px) | Thin strokes vanish, counters fill in, detail turns to mush | Isolated marque only; strokes ≥ ~1/8 of mark width; no interior gaps narrower than 1px at 16px |
| Social avatar (circle crop) | Corners clipped, mark feels off-center | Marque sits within the inscribed circle with clear space |
| Embroidered patch / hat front | Thread can't hold fine gaps or tiny text; curved crown distorts | Gaps ≥ ~1.5mm at final size; no text under ~5mm cap height; test horizontal lockup on a curved front panel |
| Woven apparel tag | Low resolution weave, narrow tag | Simplified secondary lockup; one color |
| Apparel rivet / button / laser etch | Single depth, tiny, no color | Marque in one flat color, survives as pure outline or pure fill |
| Environmental signage | Viewing distance, lighting, fabrication (cut metal, neon, routed wood) | Mark reads from distance; can be fabricated as solid pieces without floating islands |
| Vehicle wrap | Door seams, handles, curved panels, motion | Primary or horizontal lockup placed away from seams; legible at speed |
| Packaging (front + narrow side panel) | Side panel too narrow for primary lockup | Vertical/stacked alternate; pattern from mark DNA on wraparound |
| Website header & mobile nav | Wide vs cramped spaces | Horizontal lockup on desktop, marque-only on mobile |
| Email signature / documents | Small, often rendered as low-res image | Horizontal lockup legible at ~150px wide |
| Reversed out (white on dark / photo) | Negative-space tricks invert meaning | Check that splices still read when inverted |
| One-color print / fax / stamp | Relies on color contrast | Everything works in solid black |

If more than one application fails for the same reason (e.g., gaps too narrow), fix the geometry once in the core mark rather than patching each application.
